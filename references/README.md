# References

Store public, licensed, or properly redacted reference material used by the Fund Finance skill.

Good candidates:
- Fund finance market reports
- Public credit agreements and exhibits
- Public BDC filings
- NAV / subscription facility primers
- ABL underwriting references
- Borrowing-base definitions
- Covenant and cash-sweep examples
- Public rating-agency methodologies

Do not commit confidential borrower information, MNPI, proprietary bank materials, credentials, or unredacted internal documents.

When adding a reference, use a descriptive filename and note the source and date where practical.
