# Scripts

Use this directory for deterministic tools that support fund finance and ABL analysis.

Planned examples:
- NAV / LTV calculators
- Borrowing-base calculators
- Weighted-average advance-rate calculations
- Concentration-limit tests
- Portfolio stress tests
- Compliance-certificate checks
- Loan-tape normalization
- Document table extraction helpers

Scripts should expose assumptions clearly and avoid silently changing source data.
