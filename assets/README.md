# Assets

Store reusable non-sensitive templates and visual assets for fund finance and ABL work.

Examples:
- Blank underwriting templates
- Loan-tape schemas
- Borrowing-base templates
- Cash-flow diagrams
- Structure charts
- Covenant review templates
- Stress-test layouts
- Presentation graphics

Prefer blank, synthetic, public, or properly redacted materials. Do not commit confidential borrower data, MNPI, proprietary bank materials, or credentials.
